# IEDT Bridge — Lightroom Classic ↔ Sony Imaging Edge 评分桥

把 Sony Viewer(IEDT) 的快速选片能力接入 Lightroom 工作流：从 LR 菜单一键进入
Viewer 选片打分，回来再一键把评分同步进 LR 目录。

## 安装（一次性）

1. 打开 Lightroom Classic → 菜单 **文件 → 增效工具管理器**
   （File → Plug-in Manager）
2. 点左下角 **添加**（Add），选择 `iedt-bridge.lrplugin` 文件夹 → **添加增效工具**
3. 选中左侧的 **IEDT Bridge**，确认状态为"已启用"
4. 在下方的设置面板确认两个路径（默认值通常已正确）：
   - Sony Viewer：`E:\APP\Sony\Imaging Edge\Viewer.exe`
   - Python：`E:/APP/miniconda3/python.exe`

## 使用

菜单位置：**图库 → 增效工具额外命令**（Library → Plug-in Extras）

### 去 IEDT 选片
在图库选中照片（选多少同步多少）→ 执行本命令：
1. 选中照片的 LR 评分/标签会先写入 ARW（Viewer 里能看到当前状态）
2. 自动启动 Viewer 并定位到照片所在文件夹
3. 在 Viewer 里快速浏览、打星（工具→评价）、打颜色标签

### 从 IEDT 同步评分
在 Viewer 里选完片回到 LR，选中同一批照片（可 Ctrl+A 全选文件夹）→ 执行本命令：
- Viewer 打的星级和颜色标签被写回旁车，并**直接更新 LR 目录**（评分、标签立即可见，可按星级过滤筛选片）

## 技术说明

- 评分存储机制：Viewer 用 ARW 内嵌 XMP（TIFF tag 0x02BC），LR 用旁车文件；
  本插件内置的 `xmp_bridge.py` 在两者间原位搬运——写 ARW 时字节等长替换，
  不移动任何 TIFF 偏移，文件结构与 Sony 解析器完全兼容，图像数据零改动。
- 仅同步**评分和颜色标签**； develop 编辑参数两套引擎互不兼容，不做转换。
- 两个方向的命令都幂等：重复执行只更新有变化的照片。
- 也可以脱离 LR 单独使用桥脚本：
  `python xmp_bridge.py --apply "D:\pictures\照片\RAW"`（LR→Viewer）
  `python xmp_bridge.py --reverse "D:\pictures\照片\RAW"`（Viewer→LR）

## 文件清单

| 文件 | 作用 |
|------|------|
| Info.lua | 插件清单与菜单注册 |
| CullInIEDT.lua | “去 IEDT 选片”命令 |
| SyncFromIEDT.lua | “从 IEDT 同步评分”命令 |
| common.lua | 共用工具（路径、列表文件、旁车解析） |
| PluginInfo.lua | 插件管理器设置面板 |
| xmp_bridge.py | 核心桥接脚本（Python，亦可独立使用） |
