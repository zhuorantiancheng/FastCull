# FastCull 2.7.7 · macOS 源码构建修复

- 修复源码包内 `scripts/build-macos.py` 的 LibRaw 构建目标：改用 `lib/libraw_r.la` 和 `lib/.libs/libraw_r.a`，macOS 工作流在 Apple Silicon 和 Intel 上都能完成构建、测试和打包。2.7.6 的源码包在 Mac 上按文档构建会失败，请使用本版源码包。
- 功能与 2.7.6 相同，见下。

## 2.7.6 的载入已有裁切与预览提速

- 载入已有裁切：从 Lightroom Classic 打开时后台直接读取目录中的裁切边界、角度和方向，无需先把修改保存到 XMP；Bridge 和独立打开读取 RAW 旁车或 JPEG 内嵌 XMP 中已保存的 ACR/LR 裁切。读取不写照片，也不登记为需要同步的新修改。
- 100% 全尺寸显示不再逐像素复制 25.6 MP 缓冲，6192×4128 图片的纹理准备从约 27 ms 降到可忽略。
- 网格与胶片带先用相机内嵌小图占位，200 px 预览到达后原位替换；Sony 等大 TIFF 源首屏和滚动更快。
- 解码线程上限从 4 提到 12：缩略图批量吞吐 8 线程约为 4 线程的 1.9 倍，12 线程再快 25～35%，16 线程以上饱和。
- 2.7.4 的 100% 切图过渡、裁切工具、曝光快调、整理计划及 LR/Bridge 同步行为保持不变。

## 2.7.4 的 100% 切图过渡

- 修复 100% 过片时先显示适屏预览再放大的跳变。
- 单图和对比模式下，过渡预览沿用当前倍率与相对查看位置，全尺寸图就绪后只更新清晰度。
- 全尺寸信息由实际解码来源提前提供，不按后缀、机型或上一张照片猜测；信息尚未就绪时保持加载提示，不插入适屏画面。

## 2.7.3 的星级筛选文案

- 星级比较选项改为“大于等于”和“小于等于”，保持原有筛选逻辑。

## 2.7.2 的 Bridge 快捷键恢复

- 修复 Bridge 快捷键助手退出后，Ctrl+Alt+K 持续无响应的问题。
- 增加助手心跳与自动恢复，启动暂时失败也会自动重试；健康状态不重复启动进程。

## 2.7.1 的 Windows 分发功能

- 提供 Windows x64 安装程序与完整便携包，无需 Python 或 Rust 运行环境。
- 安装时可选择注册 Adobe Bridge 和 Lightroom Classic，支持 Ctrl+Alt+K 启动。
- 支持升级、取消注册及卸载，保留照片、XMP 和恢复备份。
- 修复 Lightroom 插件安装位置变更后仍引用旧内置程序的问题。
- 保留 2.7.0 的界面、快捷键、启动优化和预览缓存行为。

支持 Windows 10/11 x64；RAW 格式初步支持 ARW、CR2、NEF，另支持 JPG/JPEG。安装器界面为英文，应用为中文。安装包暂未签名。

Bridge 需先启动过一次，安装后允许 FastCull 启动脚本。Lightroom 仅支持 Classic；详情见 README。
