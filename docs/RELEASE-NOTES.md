# FastCull 2.7.4 · 100% 切图过渡

- 修复 100% 过片时先显示适屏预览再放大的跳变。
- 单图和对比模式下，过渡预览沿用当前倍率与相对查看位置，全尺寸图就绪后只更新清晰度。
- 全尺寸信息由实际解码来源提前提供，不按后缀、机型或上一张照片猜测；信息尚未就绪时保持加载提示，不插入适屏画面。

## 2.7.3 的星级筛选文案

- 星级比较选项改为“大于等于”和“小于等于”，保持原有筛选逻辑。

## 2.7.2 的 Bridge 快捷键恢复

- 修复 Bridge 快捷键助手退出后，Ctrl+Alt+K 持续无响应的问题。
- 增加助手心跳与自动恢复，启动暂时失败也会自动重试；健康状态不重复启动进程。

## 2.7.1 的 Windows 分发功能

- 提供 Windows x64 安装程序与完整便携包，无需 Python 或 Rust 运行环境。
- 安装时可选择注册 Adobe Bridge 和 Lightroom Classic，支持 Ctrl+Alt+K 启动。
- 支持升级、取消注册及卸载，保留照片、XMP 和恢复备份。
- 修复 Lightroom 插件安装位置变更后仍引用旧内置程序的问题。
- 保留 2.7.0 的界面、快捷键、启动优化和预览缓存行为。

支持 Windows 10/11 x64；RAW 格式初步支持 ARW、CR2、NEF，另支持 JPG/JPEG。安装器界面为英文，应用为中文。安装包暂未签名。

Bridge 需先启动过一次，安装后允许 FastCull 启动脚本。Lightroom 仅支持 Classic；详情见 README。
