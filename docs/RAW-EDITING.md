# RAW 编辑：本地显影、独立窗口与 XMP

选中 ARW、NEF 或 DNG，点击左侧 **RAW 编辑**，在独立窗口中加载 RAW 和对应 XMP。编辑窗口打开期间锁定主选片器，完成自动保存与回传后恢复操作。独立使用不需要安装或启动 Photoshop、Camera Raw、Lightroom 或 Bridge；显影由随程序提供的 LibRaw 原生模块完成。

当前支持曝光、白平衡、色温、色调，以及 **对比度、高光、阴影、白色、黑色、自然饱和度、饱和度** 七项基础调整。显示目标为 sRGB。与 LR/ACR 的互通通过 XMP 字段实现，本地画面使用自己的显影和色调模型。

## 使用

1. 在主窗口选中照片，打开 **RAW 编辑**。先显示文件中的快速预览，再在后台加载适屏 RAW 显影。
2. 在“色调”和“颜色”分组调整参数。曝光与七项基础滑杆由 GPU 实时显示；白平衡调整会触发后台 RAW 重新处理。顶部 RGB/亮度直方图根据本地 sRGB 预览采样，随调整更新。
3. 白平衡可选“保留原设置”“原片”或“自定义”。自定义色温范围为 2000–50000 K，色调为 -150–150。
4. **灰点吸管**：点击应为中性灰或白、未过曝的区域，获得可继续微调的白平衡估计，再等待本地显影刷新。过暗、剪切或无效样点会提示重新取样。
5. 在画面上直接用 **滚轮缩放**，以鼠标位置为中心；拖动平移，双击或按 **Z** 在适屏与 100% 之间切换。右侧“查看”可选适屏、100%，或直接修改百分比（最高 800%）。100% 按原图像素和屏幕物理像素计算；放大后自动加载全尺寸，替换预览时保持倍率与位置。裁切模式使用独立的适屏裁切画布。
6. 底部星级控件与主选片器一致，支持 **0–5** 快捷评分；点击 **裁切 T** 进入相同的裁切编辑器。锁图标切换比例锁定，拖角可自动适应横竖比例。
7. 点 **保存调整到 XMP** 可随时提交。关闭窗口时会自动保存评分、显影参数以及当前尚未点“应用”的裁切；取消裁切只撤销这次裁切草稿。等待保存和回传完成后才关闭；失败时保留窗口与草稿，可修正问题后重试。

分组中的“预览”开关临时比较调整前后，不改变保存参数。重新加载 RAW/XMP 会丢弃未保存调整并重新读取文件或 LR 配方。

## 色彩与兼容边界

本地管线现在保留高精度线性相机数据，在浮点 ProPhoto 工作空间应用白点与配置文件，再处理曝光、Look、色调及基础调整，最后转换为 sRGB。中间缓冲和缓存保留负值及大于 1 的高光；不在显影前半段压成 8 位 sRGB。保存编辑仍只修改元数据，不重新编码 RAW 图像数据。

| 内容 | 当前行为 |
| --- | --- |
| 原片白平衡 | 保留相机实际通道增益；界面色温/Tint 从这些增益估算 |
| 自定义白平衡 | 原生和 Rust 共用 Robertson 白点模型，Tint 距离标度为 1/3000 |
| 机型 DCP | 支持双光源矩阵插值、前向矩阵、Hue/Sat 校正、Look 表、显式色调曲线及曝光基线偏移 |
| 实际配置文件 | 在直方图下显示；缺少所请求配置文件时明确报告回退 |
| Adobe Color 等增强 XMP 配置文件 | 暂不执行其增强处理；优先回退对应机型 Adobe Standard DCP，原 XMP 名称保持原样 |
| 没有可用 DCP | 使用 LibRaw 相机矩阵与本地默认色调，界面提示 |
| 蒙版及其他未知显影设置 | 保留 XMP 和资源，不参与本地画面处理 |

DCP 从本机 Adobe 用户/系统配置文件目录只读查找，也可通过 `FASTCULL_DCP_DIR` 指定搜索目录，或用 `FASTCULL_DCP_PROFILE` 指定与机型匹配的 DCP 文件。程序不分发 Adobe 配置文件；未安装 Adobe 时仍可使用相机矩阵显影或自行提供 DCP。

**相同 XMP 参数仍不代表与 Lightroom/ACR 像素等价。** 无显式曲线的 DCP 使用公开经典 SDR 曲线的稀疏单调近似；七项基础调整采用本地模型，尚未复现当前 Lightroom ProcessVersion 的全部算法。DNG 的所有内嵌配置文件/校准标签也尚未完整贯通。详见 [色彩管线](COLOR-PIPELINE.md)。

灰点吸管从显示处理前的相机采样数据反解白点，不受当前曝光、色调曲线或 Look 影响；逐通道检查过暗和传感器剪切，再对有效邻域平均。它用于中性物体，不能把有色物体当作已知白色。缺少有效原片白平衡时不会把 6500 K / 0 初值报告为相机参数。

处理版本保持原样：旧 PV 5.0/5.7 的曝光使用 `Exposure`，范围 ±4 EV，对比度使用 `Contrast`，范围 -50–100；旧流程不支持映射的高光、阴影、白色、黑色会禁用。现代已识别流程使用 `Exposure2012`、`Contrast2012` 等字段，曝光范围 ±5 EV，七项基础调整通常为 -100–100。自然饱和度和饱和度可跨这些流程使用。无法识别或存在歧义的版本相关编辑会拒绝保存，不自动升级处理版本。

## 从文件、Bridge 或 Lightroom 读取

独立或从 Bridge 打开时，读取同名 `.xmp`；DNG 没有旁车时读取内嵌 XMP，旁车存在时优先使用旁车。原片白平衡没有可用色温/色调时，不凭空补出一组“相机参数”。

从 Lightroom 插件打开时，RAW 窗口可按需取得当前目录中尚未手动保存到磁盘的完整配方。插件使用 ORIGINAL 导出到私有缓存，保留 RAW、XMP 和相对 `.acr` 等资源；这一步需要原来的 Lightroom 会话仍在运行。选片器的本地显影不调用 Photoshop 或 Camera Raw。目录中的配方可完整保留，但画面仍受上面的本地色彩模型边界限制。

同一原片同时选择多个 LR 虚拟副本会报告歧义；请只选择所需副本后重开。修改插件文件后，应在 Lightroom 插件管理器重新载入插件。

## 保存与同步

- **ARW/NEF**：原子保存同名 XMP 旁车，保留其他命名空间及未修改字段。
- **DNG**：先原子保存旁车，再由本地代码把 XMP 写入 DNG 内部，不调用 Adobe。通过同目录临时副本追加 XMP 与新 IFD0，确认后原子替换；原有图像条带、瓦片和其他原始字节保持原位置，不重新编码图像。元数据及文件哈希会改变。
- DNG 内嵌写入对 Classic TIFF 布局进行验证；BigTIFF、超出 32 位偏移范围、损坏目录或只读文件会拒绝更新。旁车已保存而内嵌失败时明确提示，允许重试。

导入 LR 完整配方时只合并显影内容，保留原片星级、标签、旗标及其他非显影元数据；在 RAW 窗口明确修改的星级会随保存写入。需要的相对资源随保存保留；已有同名资源内容不同时停止，不覆盖共享资源。打开后原片或 XMP 被其他操作改动，保存会拒绝覆盖，需重新加载后再编辑。

每次成功保存生成独立回执，主进程按顺序登记星级、裁切、方向、曝光、WB 和实际修改的基础子项。显式 0 是有效重置，未修改项不会顺带同步。LR 同步只更新相应字段，并核对 SDK 读回；仅同步星级不会确认 WB 或基础调整。RAW 编辑期间主窗口锁定；编辑窗口自动保存并确认回执后恢复主窗口。失败回执保留并报告。

LR/ACR 已打开照片时可能保留目录或内存状态。LR 可用插件同步；Bridge/ACR 应重新读取照片元数据。数值互通不保证原编辑器与本地画面一致。

## 性能策略

- 独立进程承载 RAW 窗口，文件读取、显影、图像解码与保存放在后台；普通选片不启动 RAW 编辑器或任何 Adobe 进程。
- 先显示内嵌快速预览，再后台生成长边最多 **1600 像素**的适屏显影；选择 100% 或放大超过适屏时按需加载全尺寸，随后回到适屏可继续复用全尺寸纹理。快速预览可能带有相机或原软件的烘焙色彩，与随后本地显影有差异。
- 曝光与七项基础调整直接由 GPU 处理，不为每次滑杆变化重解 RAW。WB 的 RAW 请求采用 **250 ms 去抖**，松开滑杆后处理；只保留最新排队结果，取消过期处理，旧结果不替换新图。
- 当前一张照片的 RAW 解包缓冲可复用，重复显影不必每次重新 unpack；路径、文件大小或修改时间变化时重建。适屏允许半尺寸解码与较快插值，全尺寸使用更高质量插值。
- 线性浮点缓存使用独立版本命名空间，按照片身份、文件状态、配方和输出尺寸区分，并校验实际 DCP 指纹；旧 8 位预览不会混用。只清理应用标记的缓存，不扫描或删除照片目录。缓存限制和取消机制不消除大 RAW 首次解码及全尺寸处理的成本。
- 灰点吸管使用有界小采样图和邻域平均，不复制整张全尺寸图像，也不在点击事件中同步执行 RAW 显影。
