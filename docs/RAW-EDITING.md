# RAW 编辑：本地显影、独立窗口与 XMP

选中 ARW、NEF 或 DNG，点击左侧 **RAW 编辑**，在独立窗口中加载 RAW 和对应 XMP。主选片窗口可继续切图、评分和筛选。独立使用不需要安装或启动 Photoshop、Camera Raw、Lightroom 或 Bridge；显影由随程序提供的 LibRaw 原生模块完成。

当前支持曝光、白平衡、色温、色调，以及 **对比度、高光、阴影、白色、黑色、自然饱和度、饱和度** 七项基础调整。显示目标为 sRGB。与 LR/ACR 的互通通过 XMP 字段实现，本地画面使用自己的显影和色调模型。

## 使用

1. 在主窗口选中照片，打开 **RAW 编辑**。先显示文件中的快速预览，再在后台加载适屏 RAW 显影。
2. 在“亮”和“颜色”分组调整参数。七项基础滑杆由 GPU 实时显示；曝光和白平衡调整会触发后台 RAW 重新处理。
3. 白平衡可选“保留原设置”“原片”或“自定义”。自定义色温范围为 2000–50000 K，色调为 -150–150。
4. **灰点吸管**：点击应为中性灰或白、未过曝的区域，获得可继续微调的白平衡估计，再等待本地显影刷新。过暗、剪切或无效样点会提示重新取样。
5. 需要检查细节时点 **加载全尺寸 / 100%**，拖动画面查看；再次点击可回到适屏。
6. 点 **保存到 XMP** 才提交编辑。取消未保存调整会丢弃草稿；通过标题栏关闭有草稿的窗口时会询问，保存期间不能直接关闭。

分组中的“预览”开关临时比较调整前后，不改变保存参数。重新加载 RAW/XMP 会丢弃未保存调整并重新读取文件或 LR 配方。

## 色彩与兼容边界

LibRaw 读取 RAW 中的相机色彩信息、DNG 色彩矩阵及原片白平衡，完成传感器解码、白平衡和曝光处理，再转换到 sRGB。本地窗口应用已有的裁切与方向，并通过 GPU 显示七项基础色调调整。屏幕预览为 8 位 RGB/RGBA，保存编辑不重新编码 RAW 图像数据。

| 内容 | 当前行为 |
| --- | --- |
| 曝光、白平衡、七项基础调整 | 读取并编辑对应 XMP 参数；本地模型负责画面显示 |
| 相机矩阵、原片白平衡、裁切与方向 | 供本地 RAW 显影使用 |
| XMP 配置文件名称、DCP Look、Adobe 曲线、蒙版及其他未知显影设置 | 保留 XMP 与相关资源；本地引擎不重现这些 Adobe 算法 |
| sRGB | 本地预览的目标色彩空间 |

因此，**相同 XMP 参数不代表与 Lightroom/ACR 像素等价**。配置文件名称显示在界面中供核对，并不表示本地引擎已执行该 Adobe 配置文件的全部效果。已有 LR/ACR 深度调整时，本地画面可能与原编辑器不同。

色温和 Tint 使用本地白平衡模型。Tint 的数值标度没有与 Adobe 的专有校准精确对齐；同一组 K/Tint 数字在两个引擎中可能产生不同颜色。灰点吸管从显示图的小型采样图估计中性点，并非 Adobe 吸管的实现。缺少有效起始白平衡时，6500 K / 0 仅作为估计求解的初值，不当作相机原片白平衡；结果需查看重新显影后的画面并微调。

处理版本保持原样：旧 PV 5.0/5.7 的曝光使用 `Exposure`，范围 ±4 EV，对比度使用 `Contrast`，范围 -50–100；旧流程不支持映射的高光、阴影、白色、黑色会禁用。现代已识别流程使用 `Exposure2012`、`Contrast2012` 等字段，曝光范围 ±5 EV，七项基础调整通常为 -100–100。自然饱和度和饱和度可跨这些流程使用。无法识别或存在歧义的版本相关编辑会拒绝保存，不自动升级处理版本。

## 从文件、Bridge 或 Lightroom 读取

独立或从 Bridge 打开时，读取同名 `.xmp`；DNG 没有旁车时读取内嵌 XMP，旁车存在时优先使用旁车。原片白平衡没有可用色温/色调时，不凭空补出一组“相机参数”。

从 Lightroom 插件打开时，RAW 窗口可按需取得当前目录中尚未手动保存到磁盘的完整配方。插件使用 ORIGINAL 导出到私有缓存，保留 RAW、XMP 和相对 `.acr` 等资源；这一步需要原来的 Lightroom 会话仍在运行。选片器的本地显影不调用 Photoshop 或 Camera Raw。目录中的配方可完整保留，但画面仍受上面的本地色彩模型边界限制。

同一原片同时选择多个 LR 虚拟副本会报告歧义；请只选择所需副本后重开。修改插件文件后，应在 Lightroom 插件管理器重新载入插件。

## 保存与同步

- **ARW/NEF**：原子保存同名 XMP 旁车，保留其他命名空间及未修改字段。
- **DNG**：先原子保存旁车，再由本地代码把 XMP 写入 DNG 内部，不调用 Adobe。通过同目录临时副本追加 XMP 与新 IFD0，确认后原子替换；原有图像条带、瓦片和其他原始字节保持原位置，不重新编码图像。元数据及文件哈希会改变。
- DNG 内嵌写入对 Classic TIFF 布局进行验证；BigTIFF、超出 32 位偏移范围、损坏目录或只读文件会拒绝更新。旁车已保存而内嵌失败时明确提示，允许重试。

从 LR 取得的完整配方只合并显影内容，保留原片星级、标签、旗标及其他非显影元数据。需要的相对资源随保存保留；已有同名资源内容不同时停止，不覆盖共享资源。打开后原片或 XMP 被其他操作改动，保存会拒绝覆盖，需重新加载后再编辑；主窗口对同一照片的评分也可能使旧草稿需要重新加载。

每次成功保存生成独立回执，主进程按顺序登记曝光、WB 和实际修改的基础子项。显式 0 是有效重置，未修改项不会顺带同步。LR 同步只更新相应字段，并核对 SDK 读回；仅同步星级不会确认 WB 或基础调整。关闭 LR 主选片窗口后，会等待仍打开的 RAW 窗口完成回执，再结束会话同步；失败回执保留并报告。

LR/ACR 已打开照片时可能保留目录或内存状态。LR 可用插件同步；Bridge/ACR 应重新读取照片元数据。数值互通不保证原编辑器与本地画面一致。

## 性能策略

- 独立进程承载 RAW 窗口，文件读取、显影、图像解码与保存放在后台；普通选片不启动 RAW 编辑器或任何 Adobe 进程。
- 先显示内嵌快速预览，再后台生成长边最多 **1600 像素**的适屏显影；全尺寸只在明确请求后加载。快速预览可能带有相机或原软件的烘焙色彩，与随后本地显影有差异。
- 七项基础调整直接由 GPU 处理，不为每次滑杆变化重解 RAW。曝光和 WB 的 RAW 请求采用 **250 ms 去抖**，松开滑杆后处理；只保留最新排队结果，取消过期处理，旧结果不替换新图。
- 当前一张照片的 RAW 解包缓冲可复用，重复显影不必每次重新 unpack；路径、文件大小或修改时间变化时重建。适屏允许半尺寸解码与较快插值，全尺寸使用更高质量插值。
- 预览缓存按照片身份、文件状态、配方和输出尺寸区分；只清理应用标记的缓存，不扫描或删除照片目录。缓存限制和取消机制不消除大 RAW 首次解码及全尺寸处理的成本。
- 灰点吸管使用有界小采样图和邻域平均，不复制整张全尺寸图像，也不在点击事件中同步执行 RAW 显影。
