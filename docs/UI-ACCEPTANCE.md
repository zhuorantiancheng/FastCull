# 需求与交互核对：2.4.0

当前交付 2.4.0 仅启用 ARW、CR2、NEF、JPG/JPEG，其他 RAW 留待后续检查。所有入口混选跳过不支持文件。CR2/NEF 优先全尺寸内嵌图，小预览才在 100% 后台解码 RAW；JPG 直接读原图并更新内嵌元数据。关闭说明和 LR 手动同步入口使用“照片元数据”措辞，文件树、曝光、对比和关闭流程保持原有布局。146 项回归及原生窗口检查通过，见 `formats-validation-2.4.0.json`。

沿用 2.3.1 的 Bridge 多目录加载和实际移动：连续移动记住目标，多选批量后台执行，RAW/XMP/ACR 同行；完成后更新文件树及照片路径。控件集中在文件树底部，目标弹窗允许选择或粘贴路径。M 快捷键与文本/菜单/弹窗输入隔离；默认移动后下一张，评分在排队照片上暂不可用，浏览和对比保持照片索引。LR 整理计划、同步范围和关闭选择沿用既有逻辑。验证及边界见 [BRIDGE.md](BRIDGE.md)。

## 2.3.1：文件树与混选

文件树滑轨与数量分开布局，名称和数字统一行高，长名称保持截断。有效拖拽目标显示蓝色边框和移动光标，无效目标显示红色边框和禁止光标；原有筛选、曝光、对比和同步按钮位置保持。混合选择静默跳过非 ARW 文件，不新增常驻提示或过滤控件。常规与最小窗口的原生截图、布局与输入回归通过，见 `tree-validation-2.3.1.json`。

## 2.2.0：文件夹树与整理计划

按用户确认的完整保留 LR 数据方案：多文件夹自动显示树，支持搜索、子文件夹范围、本次加载数量、新建实际目录、Ctrl/Shift/Ctrl+A 多选、拖到目标或选择目标保存计划、取消计划。移动不直接改动文件；文件夹与元数据联合筛选仍使用原照片索引，评级、曝光、缓存和对比保持原始身份。

有计划时关闭框明确同步修改和整理计划；没有计划时仍只自动同步星级。退出后 SDK 先写回已确认字段，再建立 LR 待整理集合，并选中第一组原对象。实际移动由 LR 文件夹面板完成；再次“同步选片会话”核对原 UUID 路径，定位下一组。不会移出目录、重新导入、删除原集合或直接编辑目录数据库。

计划失败独立于字段确认进度，重试不重复曝光历史；损坏计划保留原文件。文件树左对齐、绘制文件夹图标、选中高亮；长路径弹窗和“取消此项”控件限制宽度，完整路径采用悬停说明。详见 [文件夹操作说明](FOLDERS.md)。

108 项回归（66 Rust、38 Lua/SDK、2 日志分析、2 像素检查）和 Clippy 通过。两个正式窗口各 19 帧验证文件夹操作、计划筛选和退出收据，RAW 哈希不变。像素验证曾把小窗口侧栏误计入照片区域，改为实际画布边界并补充两个回归，误差标准没有放宽。数字与截图归档 `folders-validation-2.2.0.json`。

## 2.1.2：关闭提示与对比联动

关闭框内容宽度 440px，内边距 22px；标题 24px、正文 18px、说明 14px，按钮文字 16px、按钮高度 40px，控件间距 12px。内容按视口宽度调整，按钮可整项换行。LR 会话提供同步全部并关闭、仅关闭稍后同步、取消三个动作；有整理计划时主按钮为同步并整理后关闭。独立模式提供直接关闭与取消。

对比先取消联动，分别放大并移动到各自主体，再启用联动。开启开关不改变任一视图；缩放使用共同倍率，移动使用共同的图像比例增量，保留两个视图的锚点差和倍率差。任一照片到边缘时共同限制平移，防止各自裁剪造成对齐丢失。适配显示全图，但保留锚点供再次放大使用；更换候选只重置新照片的位置，参考照片的位置和倍率保持。

统一覆盖滚轮、拖动、上下键、适配/100% 按钮、F 与双击。回归先在旧逻辑复现“B 的倍率被复制为 A 的倍率”，修正后验证不同主体偏移、不同倍率、共同边界、取消联动及参考图保持。原生窗口检查常规与 640×480 尺寸；结果和截图归档 `features-validation-2.1.2.json`。正式插件与分发包版本均为 2.1.2。

## 修正的组合冲突

1. 快速连续“5 星、右箭头”曾先翻片再打星，可能修改下一张。按原始事件顺序执行，包含同帧重复按键；反向顺序也独立验证。
2. 对比中点击胶片上的另一张对比图曾被忽略。现在切换活动画面，保留两张照片身份与其视图。
3. 对比中的上下键曾只修改单图平移量。现在修改活动对比画面，联动时同步另一画面；平移量按当前大图尺寸与画面边界限制。
4. 只改星级的已关闭会话曾在自动同步后继续留在待同步列表。按导出快照检查是否还有其他字段，全部完成才移出；曝光、旗标和颜色未同步时仍保留。
5. 自动同步成功曾再弹一次 LR 成功提示。确认关闭之后成功直接返回，失败才提示并保留重试状态；手动同步仍显示结果。
6. 小窗口中颜色或曝光按钮曾拆成多行，曝光值独占一行。改为完整控件组换行，整条工具栏在带筛选侧栏的 640×480 窗口中限制为 112px 内。
7. 筛选输入框与已打开菜单保留自己的按键，不触发打星、翻片或关闭；空结果不允许修改星级/曝光。

“筛选＋对比＋曝光＋打星”组合测试直接检查保存文件与会话修订：只修改活动照片，退出筛选的照片不会被错误替换或套用另一张曝光；筛选清空后保留改动。

85 项回归（52 Rust、31 Lua/SDK、2 日志分析）与 Clippy 通过；原生窗口检查覆盖常规尺寸和带筛选侧栏的最小尺寸。另有 15 轮 UI/缓存/焦点复测和 200 次定向曝光保存复测。逐项原始数字随 `docs/features-validation-2.1.1.json` 归档。

## 仍需区分的事项

- 曝光参数确实无损保存并通过 SDK 写回，JPEG 显示是近似效果，不能重现 LR 全部显影或恢复剪裁高光。未取得有效 Exposure2012 的旧处理版本/未解析自动曝光禁用调整。
- 无整理计划时自动关闭只确认星级。有计划时关闭框明确请求同步星级、曝光、旗标和标签，以及整理计划；实际移动由 LR 原生完成。
- 回归期间出现过一次未带具体错误的曝光保存失败；后续 200 次定向曝光与 15 轮组合复测均通过，尚未确定那一次的外部文件访问原因。现有保存失败会保留原值、显示错误，不作为成功同步。真实 LR 同时自动写旁车的环境仍需要验证。
- 请关闭旧窗口，重新载入完整 2.2.0 插件后，在真实 LR 检查文件夹分组与移动、筛选、曝光、独立/联动对比及退出同步。不能仅凭本记录保证所有桌面环境都没有问题。
