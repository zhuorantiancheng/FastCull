# 文件夹操作：2.4.0

移动范围新增 CR2、NEF、JPG/JPEG。JPG 内嵌元数据随照片本身移动，避免关联同名 RAW 的 XMP/ACR；RAW 的旁车规则保持。当前仅启用 ARW、CR2、NEF 和 JPG/JPEG，其他格式跳过。详见 [格式说明](FORMATS.md)。

数量列保持右对齐，滚动条占用独立的右侧空间。拖拽时整个文件夹行都可作为目标：移动光标／蓝色边框表示可提交，禁止光标／红色边框表示当前目标不可用；同一文件夹和已排队的照片不重复提交。文件夹外显示禁止光标。冲突和权限检查沿用移动提交检查；Bridge 实际移动与 LR 整理计划的范围保持不变。

## Bridge：连续与批量实际移动

Bridge 入口打开的选片器现在可以直接移动文件；独立运行 exe 与 LR 会话不启用这个入口。多个照片目录自动展开文件树，单目录点击顶部“文件夹”即可展开。

1. 胶片或网格选中照片，Ctrl 多选、Shift 选范围，Ctrl+A 选择当前筛选结果；筛选范围外的旧选择不会参与 Bridge 移动。
2. 点击 **移动 · N 张**，选择目标文件夹，也可以粘贴其他已存在的文件夹路径。确认 **开始移动** 后进入后台队列；右键文件夹的“将已选照片移动到此处”使用同一弹窗。直接拖到文件夹行会立即加入队列。
3. 连续整理时，勾选 **移动后下一张**（默认开启）。加入队列后切到下一个未在队列中的可见照片；按 **M** 或点 **移到上次位置**，继续移到上次目标。第一次按 M 先选择目标；输入框、菜单及弹窗中的 M 不会触发文件移动。
4. 同一张照片移动成功后可以再次移动到另一个位置。目标按本次选择记忆；队列按提交顺序执行，可在前一批执行期间继续浏览和提交其他照片。已经排队的照片不重复加入，缩略图标注“移动中”，该照片暂时不可修改评分/曝光。
5. ARW 连同 `照片.xmp`、`照片.acr`、`照片.ARW.xmp`、`照片.ARW.acr` 一起移动，扩展名大小写均识别。完成后更新文件树、数量、筛选与工作路径；评分和曝光继续写到新位置，照片索引与图像缓存保持不变。
6. 新建文件夹仍用“＋”或文件夹右键；Bridge 模式新建后保留当前筛选范围，方便把当前照片移入新目录。文件树统计本次加载的照片，旧空目录会保留显示，方便继续整理或移回。
7. 队列未完成时选择关闭，会等待完成后自动关闭。遇到移动错误会留在窗口中显示结果；Bridge 显示未刷新时按 F5。

同盘使用不覆盖目标的文件重命名；跨盘先完整复制到目标目录的临时文件、刷盘并发布，之后移除源文件。目标已有同名 RAW 或任何匹配旁车会拒绝本批；执行期间新增冲突也不会被覆盖。每张照片独立提交，失败尝试回退本张；已经成功的其他照片保持新位置，失败后的本批剩余照片不继续移动。链接/重解析点文件不支持实际移动。

恢复记录保存在 `%LOCALAPPDATA%/FastCull/logs/moves/`，包含原位置、目标、完成和回退状态。断电、崩溃或外部文件占用下不能承诺整个批次原子完成；程序不会启动时自动重放/回退这些记录。失败提示和记录用于核对文件位置，无法回退的路径会明确报告。不要同时在其他应用修改正在移动的照片。

Bridge 文件移动不更新 LR 目录；照片若已纳入 LR 且需要保留目录关联，请在 LR 原生移动。Bridge 与 LR 的评分同步范围沿用 [BRIDGE.md](BRIDGE.md)。

## LR：保留完整目录记录的整理计划（原 2.2.0）

本版按用户确认的“完整保留 LR 编辑历史、集合关系和虚拟副本”方案实现。文件夹可以直接创建；移动先保存为整理计划，退出后自动同步修改并建立 LR 待整理分组，实际移动由 LR 原生操作完成。

### 选片器中的操作

1. 从 LR 选择多个文件夹中的 ARW 打开选片器，左侧自动显示文件夹树。单个文件夹也可以点击顶部“文件夹”展开。
2. 点击文件夹筛选照片，“包含子文件夹”控制是否包括后代。“全部照片”恢复整个会话。文件夹条件与星级、镜头等元数据条件同时生效。
3. 数量只统计本次加载的照片；有整理计划时按照目标文件夹计算。未加载的照片和无关文件夹不会递归扫描或自动加入选片范围。
4. 选中文件夹后点击“＋”，或右键“新建子文件夹”。这是实际创建磁盘目录，重名、权限失败和无效名称会提示。
5. 点击胶片/网格中的照片；Ctrl 多选、Shift 按当前筛选顺序选范围，Ctrl+A 选择当前筛选结果。评分、曝光等仍只修改当前活动照片，多选用于整理计划。
6. 点击“安排移动”选择目标，也可以将已选照片拖到文件夹行。计划不会移动 RAW 或旁车，也不会改变解码缓存和照片身份。选择可以保留跨文件夹，按钮显示实际选择数量。
7. “待整理”查看目标文件夹和照片名，并可以取消单项。完整路径在悬停提示中。回到原始文件夹安排移动会取消该照片的计划。

新建文件夹不等于将空目录加入 LR 目录；在 LR 完成移动时，需要在文件夹面板添加目标目录。文件夹树中的计划位置也不表示磁盘文件已经移动。

## 退出与 LR 中的操作

有待整理照片时，关闭框明确显示“同步并整理后关闭”，同步星级、曝光、旗标、颜色标签、裁切和旋转，然后建立整理分组。先同步修改，再进行实际移动，避免旁车路径改变后遗漏待同步字段。没有移动计划时显示“同步全部并关闭”，同样自动同步全部已修改字段。失败的会话保留供手动重试，见 [退出同步说明](LR-SYNC.md)。

确认关闭后 GUI 先退出，LR 后台任务读取同一会话的同步收据：

- 先把确认的照片字段写回原始 LR 对象。
- 在“集合”面板建立 `FastCull 待整理 · <会话 ID>`，按目标目录分组；使用原照片和原虚拟副本对象，不删除、不重新导入，也不修改原有集合。
- 定位第一组并选中待移动照片，显示目标路径。请在 LR 文件夹面板添加目标文件夹，将**当前选中的照片**拖入。
- 完成一组后执行“同步选片会话”。插件通过原照片 UUID 核对路径，跳过已完成的照片，定位下一组；全部完成后移出待同步会话列表。

“直接关闭”保留计划，之后使用“同步选片会话”处理；“取消”继续选片。已有待整理集合不自动删除，避免删除用户保留或自行添加的集合内容。

## 身份与失败处理

整理记录独立保存到会话清单旁的 `.folders` 文件；照片路径使用 UTF-8 十六进制编码。记录必须匹配会话 ID 和原始照片列表，不改变文件名。计划持久化成功后才更新树和筛选；批量出现照片/旁车重名或写入失败时，移动计划不部分提交。

“同步全部并关闭”及“同步并整理后关闭”的退出收据第二行均为 `all`；原有星级同步收据继续兼容。已写回的字段与待整理状态分别确认：集合创建失败会保留原计划和收据，重试不重复曝光历史；目录切换、照片缺失、原照片已在其他位置或目标目录不可访问都会保留供核对。

损坏或会话不匹配的计划不会被覆盖，不允许同步退出；可以直接关闭保留文件。新目录创建已经成功而记录写入失败时，保留目录和错误提示，不通过删除目录“回滚”。

## 验证范围

回归覆盖文件树计数、跨盘与路径组件、文件夹和元数据联合筛选、原照片字段保存、Ctrl/Shift 多选、文本输入隔离、长路径小窗口、重名及写入失败、原 UUID 和虚拟副本、SDK 集合事务、活动会话延后、自动退出、整理失败重试和完成核对。

原生窗口以两个文件夹中的私有样片副本验收；创建目录、保存两张计划并确认 RAW 哈希不变。真实 LR 的集合定位、拖动和原目录数据保留仍需实际安装后验证；SDK mock 和原生选片器截图不能替代这一步。正式证据见 `folders-validation-2.2.0.json`。

本次接口依据：[Adobe LrPhoto SDK 文档镜像](https://lrc.mcor.dev/modules/LrPhoto.html)、[Adobe LrCatalog SDK 文档镜像](https://lrc.mcor.dev/modules/LrCatalog.html)。公开的照片路径为读取字段，集合创建采用 SDK 写入事务；新集合提交后才加入照片。未采用移出目录再导入或直接修改 `.lrcat` 的方式。
