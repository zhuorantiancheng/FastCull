# FastCull Windows 独立版

适用于 Windows 10/11 x64，无需 Lightroom、Bridge、Python 或 Rust 环境。

完整解压 `FastCull-Windows-2.7.0-win64.zip`，双击 `FastCull.exe`。选择“打开照片”可多选；选择“打开文件夹”可多选文件夹，并扫描其子文件夹。也可以从资源管理器拖入照片或文件夹。不支持的文件会跳过；没有可加载照片时在窗口中显示提示，可以重新选择。

如需安装到当前用户目录并创建桌面、开始菜单快捷方式，双击 `安装.cmd`。免管理员权限。便携运行时请将 exe 和 `fastcull_raw.dll` 保持在同一目录。

进入选片界面后可使用评分、旗标、颜色标签、曝光调整、筛选、双图对比以及文件树连续和批量移动。“新窗口”可打开另一批照片，当前选片状态保留在原窗口。RAW 评分等写入 XMP 旁车，JPEG 写入内嵌 XMP；移动包含对应旁车。独立版不连接 LR 目录；如照片已被 LR 收录，应在 LR 中整理路径以保留目录关系。

当前启用 ARW、CR2、NEF、DNG、JPG/JPEG/JPE。100% 查看按每份 RAW 的有效输出尺寸检查内嵌预览，尺寸来自文件元数据和实际 JPEG 图像头；最大预览不足时使用 RAW 解码。机型、拍摄裁切设置和预览设置都会影响尺寸，不按后缀规定固定分辨率。

日志位于 `%LOCALAPPDATA%/FastCull/logs`。LibRaw 原始源码、适配层源码与重建脚本随包提供，许可见 `THIRD-PARTY-NOTICES.txt`。

2.7.0 保持界面与操作不变，增加适屏预览原生缩小解码、按画布尺寸加载、停留后的 100% 后台预热，以及切图结果复用。100% 仍按每份照片实际分辨率显示；首次点击未命中缓存时仍需等待解码。
